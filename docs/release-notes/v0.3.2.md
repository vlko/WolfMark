A small update on top of the new editor in 0.3.1: room to write, text the size you like and emoji in colour.

## ✨ New

- **Full view** – press **F11** (or the new button before *+ New*) and the note fills the window: the day heading, the formatting buttons and the editor stay; tags, calendar, history and the time gutter step aside. A bar under the date shows when the note was created and last edited. **F11**, **Esc** or **×** bring the rest back. On macOS F11 is taken by the system – use **Fn+F11** or the button.
- **Font size from the keyboard** – **Ctrl +** / **Ctrl −** make the editor text larger or smaller, **Ctrl 0** goes back to the default; **Ctrl + mouse wheel** works too. The shortcut follows the character on your keyboard layout, so on the Slovak layout it is Ctrl with the "+" key (the 1 key). The size is saved to Settings.
- **Colour emoji** (Windows) – emoji are drawn in colour; *Settings → Editor → Colour emoji* switches back to emoji in the text colour.

## 🛠️ Fixes

- Linux/macOS: a possible crash right after start in formatted mode (marker chips asked for a line that was not laid out yet).
- Windows: an error while drawing the editor no longer ends the app – it is written to the log (`Editor drawing failed`) and the editor carries on.
