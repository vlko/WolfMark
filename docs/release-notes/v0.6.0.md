Tags get a proper home in Settings, formatting works on whole selections, and WolfMark moves to the final .NET 11.

## ✨ New

- **Tag management** – Settings → *Tags*
  - Every tag in one list with its note count; tags you add here show up in the tag picker even before a note has them.
  - The arrow next to a tag opens its menu: **colour**, **show titles in the calendar**, **show notes** (closes Settings and filters the history), **rename** and **remove**.
  - **Rename** changes the tag in the file names of all its notes (`work_1403.md` → `job_1403.md`); the colour comes along. Renaming to a tag that already exists **merges** the two – the notes get its name and colour, and two notes from the same minute both survive.
  - **Remove** keeps the notes and only takes the tag off (`work_1403.md` → `1403.md`).
  - Note contents are never touched. If a file cannot be renamed (e.g. it is locked), the notes already renamed go back.
  - `#ClaudeCode` belongs to the Claude Code sync and keeps its name; its colour can change.
- **Simpler tag picker** – the picker in the note header now only picks tags. Colour and calendar titles appear there just while you type a new tag; existing tags are edited in Settings.
- **Formatting on every selected line** – quote, bullet list, numbered list and task apply to all selected lines, not only the first. All already formatted → back to plain text. Numbered lists count 1, 2, 3 per indent level, done tasks stay done, blank lines are left alone. `Ctrl+Shift+L` works on the selection too.
- **Code blocks from a selection** – *Code* over several lines wraps them in a ```` ``` ```` block; again removes it. Within one line it is still `` `inline code` ``.

## 🔄 Changed

- **A note's tag is only in its file name.** `#word` in the text and `tags:` in front matter are no longer tags, so `#39` (a week number, an issue) no longer turns up in the tag picker. `#word` and `#39` are still highlighted in the editor as markers within the note. An existing search index drops the old text tags by itself on the next start. Details in [ADR 0010](../adr/0010-tag-only-in-file-name.md).
- **Inline code stands out** – a soft chip behind it and a muted brick colour, so it reads as code even when the whole editor uses the monospaced font.

## 🐛 Fixed

- **Flicker when resizing the window** on Windows (colours and text switching between faded and dark, history rows drawn twice) is gone with Windows App SDK 2.6.5. The *Window rendering* diagnostic in Settings → *Appearance* is removed.
- **The editor could go blank for good** after the computer slept or the graphics driver restarted, and only a restart of WolfMark brought it back. It now redraws by itself.

## 🛠️ Under the hood

- **.NET 11** final release (SDK 11.0.100) instead of the release candidate, with its security fixes. Releases are no longer marked as pre-release.
- **Windows App SDK 2.6.5** (was 2.5), Avalonia 12.1.6 and other package updates.
- Building from source needs the .NET 11.0.100 SDK (Visual Studio 18.12 or later).
