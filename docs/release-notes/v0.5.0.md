WolfMark can live on a USB drive now: notes, settings and the search index next to the app, nothing left behind on the computer.

## ✨ New

- **Portable mode** – Settings → *General* → *Portable mode* → *Switch to portable mode…*
  - Everything WolfMark keeps – notes, settings, the search index – is copied into a `WolfMarkData` folder next to the app, and WolfMark restarts from there. A `WolfMark.portable.json` file next to `WolfMark.exe` (or `wolfmark`) marks the copy as portable.
  - Before anything happens, a warning lists what changes. You choose **Copy** (your original notes stay where they were but are no longer updated) or **Move** (the original notes folder goes to the Recycle Bin once the copy is verified).
  - Paths are stored relative to the app, so the folder keeps working on another computer, under another drive letter or after you move it.
  - Nothing is written to the computer: start at sign-in and the `.md` file association are turned off and unavailable while portable. Deleted notes go to `.wolfmark/trash` inside the portable folder, because removable drives have no Recycle Bin.
  - You can always see when you are running portable: the Settings title says *Portable*, *General* shows where the data is, and *Index & diagnostics* includes it in the copied diagnostics.
  - **Leave portable mode…** copies everything back to your user profile and your notes folder. Notes that changed replace the old versions, which go to the Recycle Bin. The portable folder is kept, so delete it yourself once you no longer need it.
  - Not offered when the app's folder is not writable (e.g. `Program Files`), or for `WolfMark.app` installed in Applications on macOS.

## 🛠️ Under the hood

- Copying notes compares file contents, not only sizes, before it skips a file that is already there.
- The search index is copied with SQLite `VACUUM INTO`, so the copy is consistent while the app keeps running.
- A damaged `WolfMark.portable.json` stops the start with a message. WolfMark does not quietly fall back to the profile and write your notes outside the portable folder.
